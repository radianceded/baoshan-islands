## 四、技术问卷答案(钉钉应用提审常被问)

### 4.1 数据安全

| 钉钉问 | 我方答 |
|---|---|
| 数据存储位置 | 阿里云华东 2 (上海) ECS,境内 |
| 数据是否出境 | 否。AI 调用走百度千帆(国内),数据不出境 |
| 用户密码如何存 | 不存。**全 SSO 登录**,用户密码归钉钉管 |
| 数据加密 | 传输全程 HTTPS(TLS 1.2+);存储 SQLite/PG 加密;密钥 HMAC-SHA256 |
| 数据备份 | 数据库每日 02:00 自动快照 → OSS 异地备份桶 → 保留 30 天 |
| 删除请求响应 | 学校提出 7 天内完成删除并出具证明 |

### 4.2 用户隐私

| 钉钉问 | 我方答 |
|---|---|
| 收集哪些用户信息 | unionId、昵称、头像 URL(仅此三项) |
| 是否收集敏感信息 | 否。学生身份证号由学校管理员预先导入,与钉钉账号通过 unionId 绑定 |
| 第三方 SDK | 仅钉钉 JSAPI 一个;无任何统计/广告 SDK |
| 隐私政策 | 提供专属隐私政策页面 URL: `https://baoshan.your-domain.com/privacy.html`(V1.5 提供) |
| 家长查看孩子数据是否合规 | 已在数据库层做强制隔离(家长仅可见绑定 unionId 对应的学生) |

### 4.3 应用可用性

| 钉钉问 | 我方答 |
|---|---|
| 可用率承诺 | ≥ 99.5% |
| 响应时延 | 接口 P95 ≤ 800 ms;AI 首字 ≤ 2 s |
| 故障响应 | 工作日 1 小时,紧急故障 30 分钟 |
| 健康检查 | `GET /api/health` 返回 db / AI / dingtalk 状态 |

### 4.4 合规承诺

- [ ] 不在应用内进行任何商业推广 / 营销
- [ ] 不收集儿童身份信息以外的任何数据
- [ ] AI 输出严格遵循儿童内容安全规范(屏蔽负面标签、温和措辞)
- [ ] 数据可一键导出归还校方
- [ ] 服务终止后 30 天内完整删除所有数据
