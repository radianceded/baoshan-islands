# baoshan_v4.7.html 拆分方案

## 现状分析
- **总行数**: 3182 行
- **JavaScript 函数**: 159 个
- **主要问题**: 单文件过大，维护困难，加载慢

## 拆分目标
将 monolithic HTML 拆分为:
1. **主 HTML 文件** - 只包含页面骨架和视图容器
2. **视图模板文件** - 各视图的 HTML 模板
3. **功能模块 JS** - 按功能拆分的 JavaScript

## 拆分结构

```
/Applications/宝山实验/
├── index.html                    # 新主文件 (约 200 行)
├── baoshan_v4.7.html            # 原文件保留备份
├── js/
│   ├── main.js                  # 入口文件
│   ├── views/                   # 视图模块
│   │   ├── dashboard.js         # 仪表盘
│   │   ├── students.js          # 学生列表
│   │   ├── student-detail.js    # 学生详情
│   │   ├── canteen.js           # 食堂管理
│   │   ├── ai-tools.js          # AI工具
│   │   ├── governance.js        # 数据治理
│   │   ├── resources.js         # 教学资源
│   │   └── awards.js            # 获奖管理
│   └── templates/               # HTML 模板
│       ├── dashboard.html
│       ├── students.html
│       └── ...
└── css/
    └── main.css                 # 提取的样式
```

## 实施步骤

### Phase 1: 提取内联脚本 (已完成部分)
- ✅ `js/api.js` - API 调用
- ✅ `js/student-service.js` - 学生服务
- ✅ `js/modules/students.js` - 学生模块

### Phase 2: 创建新主文件
1. 保留 HTML 骨架 (head, body 结构)
2. 移除所有内联 `<script>`
3. 改为模块化加载

### Phase 3: 拆分视图模板
每个视图拆分为独立的 HTML 片段，通过 JS 动态加载。

### Phase 4: 拆分 JavaScript
按功能将内联脚本拆分到 `js/views/` 目录。

## 优先级
1. **P0** - 创建 `index.html` 新主文件
2. **P1** - 提取 CSS 到独立文件
3. **P2** - 拆分各视图模块
4. **P3** - 实现懒加载

## 预期效果
- 主文件从 3182 行 → ~200 行
- 首屏加载时间减少 60%+
- 代码可维护性大幅提升
