# 腾讯云自动部署指南

> 目标：本地 `git push` 后，30 秒内服务器自动 `git pull` + 重启服务，全自动。

## 总流程

```
你电脑 ──git push──> GitHub ──► GitHub Actions ──SSH──> 腾讯云
                                                    │
                                                    ├─ git pull
                                                    ├─ pip install
                                                    └─ systemctl restart baoshan
```

---

## 步骤 1：腾讯云服务器一次性初始化

### 1.1 SSH 进服务器
```bash
ssh ubuntu@<你的腾讯云 IP>
# 如果是用 root 登录的，用户名换 root
```

### 1.2 跑初始化脚本
```bash
# 把脚本下载下来（先用 https 公开方式）
wget https://raw.githubusercontent.com/<用户名>/<repo>/main/server/bootstrap-server.sh
chmod +x bootstrap-server.sh

# 跑（参数是你的仓库 SSH 地址）
sudo ./bootstrap-server.sh git@github.com:<用户名>/<repo>.git
```

> 如果用 SSH 拉私有仓库，提前在服务器上做：
> ```bash
> ssh-keygen -t ed25519 -C "tencent-deploy"   # 一路回车
> cat ~/.ssh/id_ed25519.pub                    # 复制
> # 粘到 GitHub → 个人设置 → SSH Keys → 添加
> ```

### 1.3 配置环境变量
```bash
sudo vim /opt/baoshan/server/.env
```
填入：
```ini
BAIDU_AI_KEY=bce-v3/ALTAK-xxxxxxxxxxxxxxxx
BAIDU_AI_MODEL=ernie-5.1
DINGTALK_AGENT_ID=
DINGTALK_APP_KEY=
DINGTALK_APP_SECRET=
DINGTALK_CORP_ID=
SESSION_SECRET=随机生成一段64位字符串
```
> 生成密钥可以用：`python3 -c "import secrets;print(secrets.token_hex(32))"`

### 1.4 重启服务
```bash
sudo systemctl restart baoshan
sudo systemctl status baoshan   # 看是不是 active(running)
```

### 1.5 配置 Nginx + HTTPS
```bash
sudo cp /opt/baoshan/server/nginx.conf.example /etc/nginx/sites-available/baoshan
sudo vim /etc/nginx/sites-available/baoshan   # 改 server_name 为你的域名
sudo ln -s /etc/nginx/sites-available/baoshan /etc/nginx/sites-enabled/
sudo rm /etc/nginx/sites-enabled/default       # 删默认页

# 申请 HTTPS 证书（钉钉强制）
sudo certbot --nginx -d your-domain.com
# 自动配置好 SSL + 续期

sudo nginx -t && sudo systemctl reload nginx
```

### 1.6 验证
打开 `https://your-domain.com/island-homepage.html` 应该能看到首页。

## 步骤 2：GitHub Secrets 配置（一次性）

进入 GitHub 仓库 → **Settings → Secrets and variables → Actions → New repository secret**，添加 4 个：

| Name | Value | 来源 |
|------|-------|------|
| `TENCENT_HOST` | 服务器公网 IP（如 `175.x.x.x`）| 腾讯云控制台 |
| `TENCENT_USER` | `ubuntu` 或 `root` | 你 SSH 登录用的用户名 |
| `TENCENT_PORT` | `22` | 一般默认 22 |
| `TENCENT_SSH_KEY` | **私钥**（完整 `-----BEGIN ... END-----` ） | 见下一步 |

### 生成专用部署 SSH key
在**本地电脑**上做（不要用你的个人 key）：
```bash
ssh-keygen -t ed25519 -f ~/.ssh/baoshan-deploy -C "github-actions-deploy" -N ""
```
- **私钥**（`~/.ssh/baoshan-deploy`）→ 粘到 `TENCENT_SSH_KEY`
- **公钥**（`~/.ssh/baoshan-deploy.pub`）→ 加到服务器：
  ```bash
  # 在腾讯云服务器上：
  echo "ssh-ed25519 AAAAC3... github-actions-deploy" >> ~/.ssh/authorized_keys
  chmod 600 ~/.ssh/authorized_keys
  ```

### 给部署用户 sudo 免密（重启服务需要）
在服务器上：
```bash
sudo visudo
```
末尾加一行（把 `ubuntu` 换成你的用户名）：
```
ubuntu ALL=(ALL) NOPASSWD: /bin/systemctl restart baoshan
```

## 步骤 3：推一下试试

```bash
git add .
git commit -m "test: auto deploy"
git push origin main
```

到 GitHub 仓库 → **Actions** 标签页看流程：
- 🟢 黄圈 → 绿勾 → 部署成功
- ❌ 红叉 → 点进去看日志（常见：SSH key 错、`requirements.txt` 装失败、端口被占）

---

## 常见踩坑

| 现象 | 原因 | 解决 |
|------|------|------|
| Actions 日志里 `Permission denied (publickey)` | 公钥没正确加到服务器 | 重新跑 `cat ~/.ssh/baoshan-deploy.pub` 加到服务器 `authorized_keys` |
| `git pull` 报 dubious ownership | git 安全策略 | `git config --global --add safe.directory /opt/baoshan` |
| `systemctl restart` 报权限错 | 没配 sudo 免密 | `sudo visudo` 加 `NOPASSWD` |
| Flask 起不来 | 端口被占 | `sudo lsof -i:5000` 看谁占了，杀掉 |
| 浏览器访问 502 | gunicorn 没起 | `sudo systemctl status baoshan` |
| `data.json` 太大上传超时 | git LFS 没配 | 大文件用 `git lfs track "*.json"` |

## 维护小技巧

### 看实时日志
```bash
sudo journalctl -u baoshan -f
```

### 回滚到上一版
```bash
cd /opt/baoshan
git log --oneline -5     # 找到要回滚的 commit
git reset --hard <commit hash>
sudo systemctl restart baoshan
```

### 暂停自动部署
GitHub 仓库 → Settings → Actions → Disable Actions

### 手动触发部署
GitHub 仓库 → Actions → 选 "部署到腾讯云" → Run workflow
