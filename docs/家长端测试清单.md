## 🚀 准备

确保本地后端在跑：
```bash

lsof -i:5050

# 没跑就启动
cd /Applications/宝山实验
PORT=5050 python3 server/app.py > /tmp/baoshan-server.log 2>&1 &
```

## 🐛 如果遇到问题

### 弹不出身份选择？
浏览器 DevTools → Application → Session Storage → **删掉所有 bs_\* 开头的键**，刷新。

### 切换身份按钮不见？
F5 强刷一次。

### 控制台看到 JS 报错？
拷过来贴给我，定位修复。

### 服务挂了？
```bash
# 看日志
tail -50 /tmp/baoshan-server.log

# 重启
kill $(lsof -ti:5050) 2>/dev/null
cd /Applications/宝山实验
PORT=5050 python3 server/app.py > /tmp/baoshan-server.log 2>&1 &
```
