# 浏览器兼容性规范

## 1. 目标浏览器支持矩阵

| 浏览器 | 最低版本 | 支持状态 | 说明 |
|--------|----------|----------|------|
| Chrome | 90+ | ✅ 完全支持 | 学校机房主力浏览器 |
| Safari | 13+ | ✅ 完全支持 | iPad 默认浏览器 |
| Firefox | 88+ | ✅ 完全支持 | 备用浏览器 |

## 2. 禁止使用的语法特性

以下语法在目标浏览器中**不支持**，禁止使用：

### 2.1 Optional Chaining (?.)
```javascript
// ❌ 禁止
const value = obj?.property?.nested;
const items = array?.[0];

// ✅ 替代方案
const value = obj && obj.property && obj.property.nested;
const items = (array && array[0]) || null;
```

### 2.2 Nullish Coalescing (??)
```javascript
// ❌ 禁止
const value = input ?? defaultValue;

// ✅ 替代方案
const value = input != null ? input : defaultValue;
// 或
const value = input || defaultValue; // 注意：这也会将 0 和 '' 视为 falsy
```

### 2.3 BigInt
```javascript
// ❌ 禁止
const big = G<student-id>90n;

// ✅ 替代方案
// 使用字符串存储大数字，或第三方库如 decimal.js
```

### 2.4 Class Fields / Private Methods
```javascript
// ❌ 禁止
class MyClass {
    #privateField = 10;  // 私有字段
    static staticField = 20;  // 静态字段
}

// ✅ 替代方案
class MyClass {
    constructor() {
        this._privateField = 10;  // 使用下划线约定
    }
}
MyClass.staticField = 20;  // 类外定义静态属性
```

## 3. 谨慎使用的 API

以下 API 需要检查兼容性后再使用：

### 3.1 IndexedDB
```javascript
// ✅ 使用 Dexie.js 封装，已处理兼容性
const db = new Dexie('StudentDB');
```

### 3.2 Fetch API
```javascript
// ✅ Safari 10.1+ 支持，但建议检查响应
fetch('/api/data')
    .then(response => {
        if (!response.ok) throw new Error('Network response was not ok');
        return response.json();
    });
```

### 3.3 CSS Grid
```javascript
// ✅ Safari 10.1+ 支持，但需要前缀
// 使用 Autoprefixer 自动处理
```

## 4. 推荐的 Polyfill

如需使用新特性，请添加 polyfill：

```html
<!-- 在 <head> 中引入 -->
<script src="https://cdn.polyfill.io/v3/polyfill.min.js?features=default,fetch,Promise"></script>
```

## 5. 测试检查清单

每次提交前，请在以下环境测试：

- [ ] Chrome 最新版 (Windows/macOS)
- [ ] Safari 最新版 (macOS)
- [ ] Safari iOS (iPad 模拟器或真机)
- [ ] 浏览器开发者工具 Console 无红色错误

## 6. 调试技巧

### 6.1 Safari 远程调试
1. iPad: 设置 → Safari → 高级 → 开启「Web 检查器」
2. Mac: Safari → 偏好设置 → 高级 → 开启「在菜单栏中显示开发菜单」
3. 用数据线连接 iPad
4. Safari → 开发 → 选择 iPad → 选择页面

### 6.2 常见 Safari 问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 页面空白 | JS 语法错误 | 检查 Console 报错，禁用新语法 |
| 样式错乱 | CSS 前缀缺失 | 使用 Autoprefixer |
| 点击无响应 | 事件委托问题 | 确保元素可点击区域足够大 |
| 滚动卡顿 | -webkit-overflow-scrolling | 添加 `overflow-scrolling: touch` |
