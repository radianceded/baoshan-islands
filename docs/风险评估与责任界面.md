## 三、高风险点(R01 / R05 / R06 / R07 / R08)详细预案

### R01 · ICP 备案延期(概率高 · 影响极高)
**触发条件**:备案进入审核 30 天仍未通过。
**预案**:
- **L1**:启用钉钉提供的预览域名 `https://*.ddapp.cn`,继续 4 个班级试点
- **L2**:与教育系统备案受理点直接对接,加急
- **L3**:必要时调整试点范围,只在本校内网 OA 入口先用

### R05 · 试点期间数据误删(概率中 · 影响极高)
**触发条件**:管理员误操作 / 程序 Bug 导致学生数据被删。
**预案**:
- **L1**:从最近一次自动快照恢复(≤24 小时数据丢失)
- **L2**:从异地备份桶恢复(≤7 天数据丢失,但完整)
- **L3**:数据库时点恢复(RDS PITR,任意时刻 ≤5 分钟)
- **配套**:每日凌晨自动备份恢复演练(每月 1 次)

### R06 · 老师使用率低(概率高 · 影响高)
**触发条件**:试点 2 周后老师日均活跃 < 50%。
**预案**:
- **L1**:简化首页,把老师最常用功能放最前
- **L2**:增加"老师专属"快捷入口(一键看本班体测异常、一键导出报表)
- **L3**:校长亲自示范,周一晨会通报"使用率最高的老师"
- **L4**:仍不达标 → 调整产品形态,直接做"周报推送到钉钉群"减少打开次数

### R07 · 家长隐私投诉(概率低 · 影响极高)
**触发条件**:有家长投诉看到了不该看的孩子信息。
**预案**:
- **L1**:24 小时内完整还原投诉数据流路径(已有访问日志)
- **L2**:确认是否真有数据泄露;若是,**1 小时内**临时关闭涉事接口
- **L3**:对相关用户做正式告知 + 致歉 + 数据删除
- **L4**:复盘:服务端权限校验在哪一层漏掉,补强后做回归测试

### R08 · 服务器故障(概率低 · 影响极高)
**触发条件**:阿里云 ECS 不可用 / 数据库连不上 / 进程 OOM。
**预案**:
- **L1**:systemd 自动重启(分钟级恢复)
- **L2**:Nginx 切换到维护页(503 + 联系电话)
- **L3**:备机启动(同区域 + 数据库连只读副本)
- **L4**:钉钉应用"维护中"公告 + 群里通知

## 四、SLA(服务级别协议)

| 项 | 承诺值 | 计算方式 | 不达标后果 |
|---|---|---|---|
| 平台可用率(月度) | ≥ 99.5% | 月内可用分钟数 / 总分钟数 | 99.0%–99.5%:服务费 5% 抵扣<br>< 99.0%:服务费 10% 抵扣 |
| 接口 P95 响应 | ≤ 800 ms | 当月所有非 AI 接口 95 分位 | 连续 3 个月不达标:免费扩容一次 |
| AI 调用成功率 | ≥ 99% | 调用次数 / 成功返回次数 | 月度低于 95%:开免费补救 1 次 |
| 故障响应(工作日 9–18) | ≤ 1 小时 | 工单创建到响应的时间 | 超时:工单累计 3 次免单 |
| 故障响应(紧急) | ≤ 30 分钟 | 同上,标记"紧急" | 超时:服务费 20% 抵扣 |
| 数据恢复 RTO | ≤ 4 小时 | 故障到恢复的总时长 | 实测演练每季度一次 |
| 数据恢复 RPO | ≤ 24 小时 | 数据丢失窗口 | 同上 |

## 五、终止条款

### 5.1 校方主动终止
- 提前 60 天书面通知
- 我方在 30 天内**完整交接**:
  - 全部源代码 + git 历史
  - 数据库完整导出
  - 上传素材完整打包
  - 12 份运维文档
  - 钉钉应用密钥归还
- 终止后我方**永久删除**所有数据副本并出具证明

### 5.2 我方主动终止
- 提前 90 天书面通知,且不得在学期中段
- 同上交接义务

### 5.3 不可抗力
- 政策变化 / 自然灾害 / 钉钉平台下架 → 双方协商,可平移到其他平台
