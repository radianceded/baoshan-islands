# 宝山实验智慧教育平台 · 功能说明

**文档用途**：供汇报者快速了解系统功能，自行组织汇报语言  
**对应版本**：v4.7 Demo 独立版  
**文件**：`宝山实验智慧教育平台.html`（双击即可运行）

## 一、系统概览

| 特性 | 说明 |
|------|------|
| 运行方式 | 双击 HTML 文件在浏览器打开，无需安装，无需网络 |
| 数据规模 | 248 名学生、20 周完整菜单、图书/活动/奖惩等关联数据 |

## 二、功能模块清单

### 1. 仪表盘（首页）

- **核心数据卡片**：学生总数、本周营养达标率、AI 辅助次数、图书流通率
- **实时图表**：学生分布（校区/年级/性别）、本周餐食选择比例
- **快捷入口**：常用功能一键跳转

### 2. 学生档案库

**列表功能**
- 全校 248 名学生列表展示
- 筛选：校区（宝林/淞宝/宝杨）、年级、班级
- 搜索：姓名模糊匹配
- 状态标签：在籍/休学/转出

**学生详情页 - 五大板块**

| 板块 | 内容 |
|------|------|
| **健康** | BMI 曲线、视力记录、体能测试（肺活量/50m/跳绳等）、AI 健康建议 |
| **餐食** | 本周 A/B 餐选择、营养摄入分析、过敏原标记、AI 餐食推荐 |
| **学业** | 各科成绩趋势图、年级排名变化、AI 学情诊断、薄弱学科分析 |
| **行为** | 获奖记录、参与活动、阅读书目、奖惩历史 |
| **档案** | 基础信息、家长信息、校服尺码、特殊备注 |

**AI 功能（右侧边栏）**
- 一键生成学情分析报告（诊断总结 + 干预建议 + 餐食推荐 + 阅读书单）
- 生成家长通知书（月度报告，可直接打印）

### 3. 食堂菜单管理

**菜单展示**
- 周选择：第 1-20 周切换
- 日视图：周一至周五，每天 A 餐 / B 餐双轨展示
- 每餐内容：主荤、次荤、素菜、汤品、水果、总热量

**营养分析**
- 本周三大营养素比例（蛋白质/碳水/脂肪）
- 高于/低于标准自动标红提醒
- 按过敏原筛选（不含坚果/海鲜等）

**数据关联**
- 学生档案页根据 BMI 自动推荐 A/B 餐
- 记录学生每日实际选择

### 4. 资源配置

| 子模块 | 功能 |
|--------|------|
| **图书管理** | 馆藏查询、借阅记录、AI 个性化书单推荐 |
| **活动管理** | 社团列表、竞赛信息、学生参与记录、活动统计 |
| **奖励管理** | 积分获取记录、积分商城兑换、表彰榜单 |

### 5. AI 工具

- **学情诊断**：基于成绩趋势生成个性化分析
- **健康建议**：结合 BMI、视力、体能数据给出干预方案
- **餐食推荐**：根据体质推荐 A/B 餐选择
- **阅读推荐**：根据学科薄弱点推荐书目
- **报告生成**：一键生成给家长的月度通知书

## 三、数据准备情况

**学生数据（248条）**
- 三个校区：宝林路校区（最多）、淞宝路校区、宝杨路校区
- 年级分布：一年级 ~ 九年级
- 每班约 25 人
- 字段完整：姓名、学号、性别、生日、家长信息、校服尺码等

**菜单数据（20周）**
- 每周 5 天（周一至周五）
- 每天 A/B 双餐
- 每餐：1 主荤 + 1 次荤 + 1 素菜 + 1 汤 + 1 水果
- 热量计算、营养配比完整

**关联数据**
- 图书借阅记录
- 活动参与记录
- 奖惩历史
- AI 生成报告样例
